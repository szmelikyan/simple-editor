## Повторная сборка в другой среде

Из корня репозитория, Python 3, только стандартная библиотека:

```sh
python3 .agents/skills/translation-edit/scripts/assemble.py verify projects/omniscient-reader-side-story
```

Состояние и все чистовые части находятся в `assembly.json`; подробности восстановления и добавления частей — в `.agents/skills/translation-edit/references/assembly.md`. Редакторский процесс описан в обычном Markdown в `.agents/skills/translation-edit/SKILL.md` и не требует конкретного провайдера. Проверены локальные файлы и сборка Python; работа через другие LLM не тестировалась.

Стилевой ориентир по указанию пользователя: чистовые главы 553–554 (`drafts/553.md`, `drafts/554.md`) в редакции коммита `bc2db9c`. При сомнениях в многословии сверяться с релевантными фрагментами этих глав: мерой сокращения, сохранением «я», условности, иронии, ритма и различий между повествованием и диалогом. Это ориентир только для данной книги; её термины не переносить в другие произведения.

Извлечение текста из сохранённых страниц RanobeLIB (Python 3.9+, стандартная библиотека, скрипты HTML не исполняются):

```sh
python3 scripts/extract_saved_chapter.py projects/omniscient-reader-side-story/sources/556.html /tmp/chapter-556.md
```

Файл назначения должен отсутствовать; пустые форматированные абзацы пропускаются, непустые абзацы и выделения сохраняются. Экстрактор предназначен для структуры предоставленных страниц RanobeLIB; не заявляется поддержка произвольных сайтов. Оригинальный HTML хранить отдельно и не перезаписывать.
