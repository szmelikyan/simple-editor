# simple-editor

[English](README.md) · **Русский**

Редактор перевода с ИИ-помощником: инструкции в обычном Markdown и Python-скрипты для сборки проверенных глав в единую книгу FB2. Подходит для разных жанров и языковых пар; терминология, стилевые ориентиры и редакторские решения хранятся отдельно для каждого произведения.

Репозиторий содержит инструкции и консольные инструменты. Текст редактирует помощник; Python-скрипты извлекают текст из сохранённых страниц и собирают проверенный результат.

## Что нужно

- Python 3.9 или новее. Скриптам достаточно стандартной библиотеки.
- ИИ-помощник, который читает и записывает локальные файлы и запускает команды. Для проверки источников нужен доступ к интернету.
- Git для клонирования и истории изменений.

## При использовании Codex: reasoning не ниже high

Для редактуры переводов в этом проекте установите уровень рассуждения (reasoning effort) **не ниже `high`**. Это требование проекта. Выбранная модель должна поддерживать этот уровень.

В конфигурации Codex задайте:

```toml
model_reasoning_effort = "high"
```

Ключ описан в [официальной документации OpenAI](https://developers.openai.com/codex/config-reference/). В интерфейсе с выбором reasoning effort установите `High` или более высокий поддерживаемый уровень. Для других ИИ-помощников используйте доступную настройку тщательного рассуждения и сохраняйте все редакторские проверки; соответствие уровней разных провайдеров не проверено.

## Как начать

```sh
git clone https://github.com/szmelikyan/simple-editor.git
cd simple-editor
```

Откройте эту папку в своём помощнике. Попросите его прочитать [AGENTS.md](AGENTS.md) и [инструкцию по редактуре перевода](.agents/skills/translation-edit/SKILL.md). Если помощник не подключает скиллы автоматически, достаточно прочитать эти Markdown-файлы напрямую.

Пример запроса:

> Отредактируй этот перевод. Сохрани смысл, голос рассказчика, терминологию и оформление. Храни произведение в projects/my-book и обновляй edited.fb2 после каждой полностью проверенной главы. При неразрешённой неоднозначности спроси меня до выбора спорного варианта.

Предоставьте перевод и, если есть, оригинал. Без оригинала помощник проверяет текст относительно предоставленного перевода и обязан указать это ограничение. Перевод с нуля выполняется по отдельному запросу.

## Файлы произведения

Разные произведения хранятся отдельно в `projects/<slug>/`:

| Путь | Назначение |
| --- | --- |
| `profile.md` | Языки, жанр, аудитория, стилевые ориентиры и порядок глав |
| `glossary.tsv` | Утверждённые термины, контекст и статус проверки |
| `decisions.md` | Повторно используемые решения и нерешённые вопросы |
| `sources/` | Предоставленные исходники, сохраняемые без изменений |
| `drafts/` | Отдельные отредактированные главы в Markdown |
| `assembly.json` | Канонический проверенный текст, явный порядок и хеши SHA-256 |
| `edited.fb2` | Единая книга из завершённых глав |
| `edited-review.docx` | Полный текст с отслеживаемыми правками относительно предоставленного перевода |

Отчёты о редактуре выводятся в разговоре или консоли. В чистовой текст они не включаются и отдельными файлами отчётов не сохраняются.

## Word с отслеживанием изменений

После редактуры создайте документ Word из парных исходных и отредактированных глав. Нужен только Python 3.9+ со стандартной библиотекой. Укажите номера в порядке чтения:

```sh
python3 scripts/build_review_docx.py projects/omniscient-reader-side-story --chapters 553 554 555 556 557 558 559 560 561 562 563 564 565 566 --output projects/omniscient-reader-side-story/edited-review.docx
```

В документ записываются настоящие вставки и удаления OOXML, включая изменения границ абзацев и выделений. Отслеживание дальнейших изменений включено. В Word используйте «Рецензирование → Исправления» и отображение «Все исправления», чтобы увидеть правки. Базой служат `sources/<id>.md`, результатом — `drafts/<id>.md`; при повторной редактуре документ показывает всю разницу с исходником.

Перед заменой документа скрипт проверяет обе версии: принятие всех правок должно воспроизводить отредактированные главы, отклонение — исходные. Сверяются текст, начертание и стили абзацев. Пустые интервалы Markdown нормализуются. Поддерживается тот же плоский набор выделений и экранирования, что в сборщике FB2; произвольный Markdown не поддерживается. Автоматические проверки и чтение файла системным импортёром macOS выполнены; отображение и команды принятия/отклонения в самом Microsoft Word не проверялись. Экспорт не требует Word, API или определённого ИИ-провайдера.

## Сборка проверенных глав

Из корня репозитория:

```sh
python3 .agents/skills/translation-edit/scripts/assemble.py init projects/my-book --title 'Моя книга' --language ru --output edited.fb2
python3 .agents/skills/translation-edit/scripts/assemble.py put projects/my-book --id '1' --order 1 --file projects/my-book/drafts/1.md --reviewed
python3 .agents/skills/translation-edit/scripts/assemble.py verify projects/my-book
```

До команды `put` создайте и проверьте файл главы. Используйте `--reviewed` только после завершения редакторской проверки. Сборщик проверяет согласованность файлов, хеши, порядок глав и дубликаты; качество перевода и наличие всех ожидаемых глав он не определяет.

Восстановление, поддерживаемый Markdown и проверка FB2 описаны в [инструкции по сборке](.agents/skills/translation-edit/references/assembly.md). Резервируйте проект целиком, включая `assembly.json`.

## Извлечение текста сохранённой страницы

```sh
python3 scripts/extract_saved_chapter.py saved-chapter.html extracted-chapter.md
```

Экстрактор поддерживает структуру HTML-читалки RanobeLIB, использованную во включённом проекте. Он сохраняет абзацы и поддерживаемые выделения, не исполняет HTML-скрипты и требует нового файла назначения. Это не универсальный загрузчик сайтов или преобразователь HTML.

## Проверки

```sh
python3 -m unittest discover -s tests
python3 .agents/skills/translation-edit/scripts/assemble.py verify projects/omniscient-reader-side-story
```

Во включённом произведении собраны проверенные русские главы 553–566 побочной истории «Точки зрения Всеведущего читателя». Имена, термины и стилевые ориентиры этого проекта относятся только к нему.

## Другие ИИ-помощники

Редакторский процесс описан в обычном Markdown, данные хранятся в Markdown, TSV, JSON и FB2 XML, инструменты написаны на Python. Автоматическое подключение скилла необязательно: прочитайте инструкцию напрямую и выполните те же команды. Локальные проверки скриптов не доказывают качество редактуры или совместимость со всеми моделями; интеграции с другими помощниками не тестировались.
